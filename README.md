## Name
General ML Template

## Description
MLOps template for the end-to-end development of AI systems as production ready Python applications. Template gives the framework needed and focusses on SWE best practices such as typing, linting, testing, logging, security, formatting and debugging.

## Installation
Ensure you have uv installed:
https://docs.astral.sh/uv/getting-started/installation/

In a terminal run:
"uv run --with cookiecutter cookiecutter HYPERLINK_TO_MLOPS_REPO"

Replace HYPERLINK_TO_MLOPS_REPO with the correct location, ensure you have the main page and end the hyperlink with a .git. For example: https://github.com/JB/mlops_template.git

Enter prompted information and you are ready to develop!
